Botão de ação; use `primary` para a única ação principal da tela e `dashed` para saídas alternativas.

    <Button variant="primary" size="lg" full onClick={save}>Salvar na coleção</Button>

Variantes: `primary` (roxo cheio + sombra colorida), `secondary` (branco com borda), `ghost` (só texto, para "voltar"/"cancelar"), `dashed` (borda tracejada, tinta suave — escapes e ações de adicionar). Tamanhos `sm` para chips de ação, `md` padrão, `lg` para o CTA de rodapé.
